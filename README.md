# 🐍 Vanya OS

**Vanya OS** — мой Python-десктоп с приложениями, играми и системными инструментами.

## ✨ Возможности

- 🖥️ Рабочий стол Vanya OS
- 📁 Проводник
- 📝 Заметки
- 🎮 Игры
- 💻 Терминал
- ⚙️ Настройки
- 🔒 Экран блокировки
- 🔎 Поиск
- 🛠️ Системные инструменты
- 🧩 Поддержка модов
- 🎨 Настройка интерфейса
- 🚀 Панель задач
- 📦 Встроенные приложения

## 🐍 Требования

Для запуска нужен **Python 3.10 или новее**.

Скачать Python можно с официального сайта:

https://www.python.org/downloads/

## ▶️ Запуск

### 🪟 Windows

Запусти:

```text
Vanya_OS_Windows.bat
```

Или:

```bash
py vanya_desktop.py
```

### 🍎 macOS

Запусти:

```text
Vanya_OS.command
```

Или:

```bash
python3 vanya_desktop.py
```

### 🐧 Linux

Запусти:

```text
Vanya_OS_Linux.sh
```

Или:

```bash
python3 vanya_desktop.py
```
